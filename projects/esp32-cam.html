Project Overview

This project explores lightweight computer vision techniques on embedded hardware using ESP32-CAM MCU. The system captures grayscale frames from an OV2640 image sensor and processes them directly on-device using custom edge detection and segmentation logic.


The primary objective was to investigate how much real-time image processing could be achieved under strict computational and memory constraints without relying on external analysis and accellerators.

System Architecture

Hardware Architecture

The system uses an ESP32-CAM module with an OV2640 camera sensor. Frames are captured in grayscale QQVGA format to reduce memory usage and improve processing throughput.


PSRAM is used for frame buffering while internal SRAM is reserved for image processing and task execution.

Firmware Architecture

The firmware is divided into dedicated FreeRTOS tasks pinned to separate CPU cores. One task continuously acquires camera frames while another performs image processing asynchronously using a queue-based pipeline.


This architecture reduces frame drops and prevents processing latency from blocking image acquisition.

Computer Vision Pipeline

The processing pipeline uses lightweight edge-based computer vision algorithms optimized for embedded execution. A Sobel-style gradient approximation is used to estimate horizontal and vertical image edges.


Pixels exceeding a configurable threshold are classified as edges and stored in a binary edge map for further segmentation and object analysis.

Real-Time Processing

Task Scheduling

Image acquisition and image processing execute independently on separate CPU cores using FreeRTOS task pinning and queue-based synchronization.


This design minimizes blocking behavior and improves overall frame handling reliability.

Memory Optimization

Several optimizations were required to maintain stable operation under limited RAM conditions, including grayscale-only processing, static memory allocation, low-resolution frame buffers, and PSRAM-backed storage.

WiFi Video Streaming

A secondary firmware implementation streams live camera frames over WiFi to a PC-hosted web server for remote monitoring and debugging.


This streaming mode was used to visualize intermediate processing stages, test camera performance, and assist with algorithm development.

Debugging & Development

Edge Detection Tuning

Significant tuning was required to achieve reliable edge extraction under changing lighting conditions and low-contrast environments.


Threshold sensitivity and image noise presented major challenges during early testing iterations.

Object Segmentation

Experimental connected-component labeling logic was developed to identify object regions from binary edge maps.


Current work focuses on improving segmentation stability and adding centroid and bounding-box extraction.
