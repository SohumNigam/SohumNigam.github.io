Project Overview

This project explores lightweight computer vision on ESP32-CAM MCU. Frames are processed directly on-device using edge detection and segmentation.

The goal was to evaluate real-time image processing under strict memory and compute constraints.

System Architecture

Hardware

ESP32-CAM with OV2640 sensor. Frames captured in grayscale QQVGA for efficiency.

PSRAM used for buffering while SRAM handles processing tasks.

Firmware

FreeRTOS tasks are split between image capture and processing using queues.

This prevents blocking and improves frame consistency.

Computer Vision Pipeline

Uses lightweight Sobel-style edge detection optimized for embedded execution.

Edge pixels are thresholded into a binary map for segmentation.

Real-Time Processing Optimizations

Task Scheduling

Separate CPU cores handle frame acquisition, buffering and processing using FreeRTOS to minimize CPU overload.

Memory Optimization

Implements grayscale, low-resolution image formats only to optimize processing framerate and CPU load under PSRAM and SRAM constraints.

WiFi Streaming

Frames are streamed over WiFi for debugging and visualization on a host PC python server using the ESP32 Wifi capibilities.

Used primarily for debugging and visualization.

Debugging

Edge Detection

Threshold tuning was required due to lighting variation and noise. Issue still persists but is minimized in constant brightness environments.

Object tracking

Object centroid calculation was significantly inaccurate due to gaps in the edge detection and segmentation logic. Was solved after reviewing and tuning parameters in the image processing pipline.
